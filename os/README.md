# Hangar OS

The OS image: Fedora Kinoite (KDE Plasma, image-based, read-only `/usr`,
atomic updates and rollback) with Hangar layered on top.

- `Containerfile`: builds it (in CI; see `.github/workflows/os.yml`).
- `files/`: copied into the image as-is:
  - `usr/share/applications/`: one launcher per Hangar app (each gets its own
    app-menu entry and taskbar icon; the Qt apps set a matching Wayland app id)
  - `etc/xdg/autostart/dev.hangar.setup.desktop`: Hangar Setup on first login
  - `etc/xdg/kglobalshortcutsrc`: the Spaces key (Mission Control key or Meta+S)
    opens the agent overview
  - `usr/share/plasma/.../updates/hangar-pin.js`: pins Hangar and Passwords to
    the taskbar (once per user)
  - `usr/lib/systemd/user/`: the daemon and the first-boot image download,
    enabled for every user together with the rootless Podman socket
  - `usr/lib/environment.d/60-hangar.conf`: where agent images come from
  - icons, wallpaper and boot splash: generated by `branding/make_assets.py`
- `iso/config.toml`: bootc-image-builder settings for the installer ISO.
