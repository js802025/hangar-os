# Hangar OS

![Hangar OS](images/hero.png)

**Hangar OS is a desktop operating system with a crew of AI agents built in.**
You use it like any computer, for your own browsing, files and apps, and
whenever there's work you'd rather hand off, you ask. Each agent gets a
computer of its own (a browser, apps and files on a desktop you can watch),
so it can do the kind of work you'd otherwise do yourself: research,
shopping, email, paperwork, code. Your **pilot** organises the crew, and you
come back to finished work.

It's Fedora Kinoite (KDE Plasma) with Hangar built into the desktop: in the
taskbar, the system-wide shortcuts, the notifications and the virtual
desktops. Updates are image-based and atomic, and can be rolled back.
