# FAQ

**Is it my everyday computer, or a server?**
Your everyday computer. Hangar OS is a normal KDE desktop for your own work,
with the crew built in. Agents run on their own hidden desktops, so they don't
take over your screen while they work.

**How much computer do I need?**
16 GB of RAM works; 32 GB or more lets you run good AI models on the machine
itself and keep several agents busy. See [Installing Hangar OS](Installing-Hangar-OS).

**Can I keep using it while agents work?**
Yes. Agents never touch your mouse, keyboard or screen. Several busy agents
do use memory and processor time, which you can cap in [Settings](Settings).

**Does it cost anything?**
Hangar is free. The AI it uses is either a subscription or API key you
already have, or local models, which cost nothing to run.

**Can agents see my screen or my files?**
No. Each agent has its own hidden desktop, and sees only folders you share
with it. See [Privacy and security](Privacy-and-security).

**What can agents actually do?**
Anything you could do on a computer with a browser and common apps:
research and compare, fill in forms and spreadsheets, write documents, review
code, sort email in a webmail tab. They're best at well-defined jobs with a
clear "done".

**What if an agent gets it wrong?**
Every task starts with a snapshot. Review the changes and undo any file, or
roll back the whole task. You can also take over its desktop at any point.

**Can it spend my money?**
Agents can't see your passwords and must ask before signing in anywhere.
Don't approve sign-ins to shops or banks for a task that doesn't need them,
and use "just this once".

**Can I use it with Obsidian?**
Yes. Notes are plain Markdown in `~/Notes`; open that folder as an Obsidian
vault.

**How do I change the shortcuts?**
System Settings → Keyboard → Shortcuts. See [Keyboard shortcuts](Keyboard-shortcuts).
