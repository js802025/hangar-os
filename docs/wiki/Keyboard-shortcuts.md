# Keyboard shortcuts

## Anywhere

| shortcut | what it does |
|---|---|
| **Meta+Space** | ask your pilot |
| **Print** or **Meta+Shift+S** | screenshot, then ask about it (also saved to Pictures/Screenshots) |
| **Meta+Shift+Space** | ask about the window you're in |
| **Meta+S** (or Mission Control on an Apple keyboard) | every space at once |
| **Meta+Print** | KDE's own screenshot app (Spectacle) |
| **Meta+Ctrl+←/→** | switch desktops, including a space on its own desktop |

Meta is the Windows key (⌘ on an Apple keyboard). Change any of these in
System Settings → Keyboard → Shortcuts.

## In Hangar

| shortcut | |
|---|---|
| Enter / Shift+Enter | send / new line |
| Ctrl+N | new chat |
| Meta+S or Ctrl+↑ | every space at once; Esc closes |

## In Notes

| shortcut | |
|---|---|
| Ctrl+N | new note |
| Ctrl+F or Ctrl+K | search |
| Ctrl+E | switch between Edit and Read |
